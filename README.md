# RateRewind 💱

A React application that calculates how much money converted into a foreign currency on a specific date in the past would be worth today.

## Features

- Fetching historical and current exchange rates from the NBP API (National Bank of Poland).
- Supported currencies: USD, EUR, GBP, CHF.
- Calculating the current value of past investments and tracking overall profit/loss.
- Saving entry history locally using `localStorage`.
- Light and dark mode support.

## Technologies

- React (Hooks: useState, useEffect, useReducer, useRef)
- Vite
- CSS3
- Fetch API

## How to run locally

1. Clone the repository:

```bash
git clone https://github.com/gregory1234567890/RateRewind.git
```

2. Go to the project directory:

```bash
cd RateRewind
```

3. Install dependencies:

```bash
npm install
```

4. Run the development server:

```bash
npm run dev
```
